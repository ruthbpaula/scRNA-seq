# scRNA-seq
Code for processing and analysis of single-cell RNA-seq data. Many thanks to Tim Wu who helped me with this.

This repository contains pipelines for:
- Processing Drosophila snRNA-seq files from scratch (from fastq, to QC, to differential expression and plotting)
- Processing human snRNA-seq files from pre-processed Seurat files (for computing basic pseudobulk stats, and plotting)
